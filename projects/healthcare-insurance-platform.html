Enterprise Demand Forecasting Platform

An end-to-end healthcare insurance analytics and machine learning platform combining enterprise-scale data generation, predictive modeling, real-time APIs, and production-oriented MLOps.

Overview

Project overview

Developed an end-to-end healthcare insurance analytics platform using Python, PostgreSQL, SQLAlchemy, and Scikit-learn to generate enterprise-scale datasets, engineer analytical features, train predictive models, and support production-oriented machine learning workflows.

Architecture

Healthcare Insurance Data→ Python Data Generation→ PostgreSQL + SQLAlchemy→ ETL & Validation→ Feature Engineering→ ML Models→ MLflow→ FastAPI

Data & Analytics Pipeline

Built modular Python and SQL workflows for healthcare insurance data generation, ingestion, transformation, validation, and feature engineering. PostgreSQL and SQLAlchemy provide the structured data layer used by downstream analytics and machine learning workflows.

Fraud Detection

Built a Random Forest classification workflow for identifying potentially fraudulent insurance claims. Applied feature engineering and SMOTE to address imbalanced classification and improve representation of minority fraud cases during model training.

Claim Status Prediction

Developed a classification pipeline for predicting insurance claim status from structured claim attributes and engineered analytical features.

Claim Cost Prediction

Built a machine learning regression workflow for estimating insurance claim costs using historical claim information and engineered claim-level features.

Model Serving

Deployed production-ready FastAPI REST APIs to expose trained models for real-time predictions and provide a reusable integration layer for downstream applications.

MLOps & Experiment Tracking

Integrated MLflow for experiment tracking, model management, reproducible training workflows, and comparison of machine learning runs across model iterations.

Engineering Practices

Implemented modular ETL pipelines, data validation, Git-based version control, and a scalable project structure separating data generation, feature engineering, model training, inference, API serving, and model operations.

Technology Stack

Python PostgreSQL SQLAlchemy Scikit-learn Random Forest SMOTE FastAPI MLflow REST APIs ETL Git Feature Engineering

Key Learning

This project demonstrates the complete machine learning lifecycle around healthcare insurance data, from structured data generation and ETL through feature engineering and predictive modeling to experiment tracking, API-based inference, and production-oriented MLOps practices.
