# Revathi Yajjavarapu AI/ML Portfolio

This folder is ready for GitHub Pages.

## Preview locally
Open `index.html` in a browser.

## Recommended GitHub Pages deployment
1. Create a GitHub repository, for example `portfolio`.
2. Upload all files and folders from this package.
3. Commit the files.
4. In GitHub, open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select the `main` branch and `/ (root)` folder.
7. Save. GitHub will provide the public portfolio URL.
